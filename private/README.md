# private/

Your own documents: resume, reviews, certificates, work samples.

**Nothing in this folder is ever committed or uploaded** (except this note and
the two `*.example.json` files). This repo is public, so originals stay on your
computer only.

- `inbox/`: put new files here, then tell Claude ("I added my resume").
- `documents/`: Claude moves each file here once it's been used.
- `private.json`, `tailor.json`: your phone number and the like for the resume
  PDFs, if you don't have the private repo cloned next to this one. The
  `.example.json` files show what goes in them.

Claude asks you before anything from these files goes on the site.
Keep your own backup of anything important: this folder isn't backed up by GitHub.
